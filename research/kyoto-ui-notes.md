# 京都府ページのUI実装記録

2026年10月5日。対象は `dist/kyoto.html` と、同ページが利用する共通の `dist/workspace.css`・`dist/app.js`。

- 京都府の独立したページを追加し、ヘッダーの「大阪府」「京都府」から府県を切り替える。現在の府県には `aria-current="page"` を付ける。京都府内は京都市・乙訓・山城・南丹・中丹・丹後から絞り込める。
- 既存の地域別調査台帳を継承。淡いスレート色の背景、白い一覧、濃紺の選択状態、青い出典リンク、日本語のシステムフォントを使用する。店名・所在地・連絡手段・判断根拠・出典を一覧の中心に置く。新しいブランド、画像素材、承認用デザイン画像は追加していない。
- S・A・B候補、条件未判定の公開記録、市町村別の調査状況を別の表示にする。候補と公開記録の件数は合算しない。26市町村は調査対象範囲であり、全件調査完了を示さない。候補は50店ずつ表示し、掲載件数の上限とはしない。
- 幅760px以下では地域ナビを横スクロールにし、絞り込みを開閉式にする。連絡先は折り返し可能で、高さ44px以上の操作領域を持つ。電話は `tel:`、確認できたメールは `mailto:`、店舗のSNS等は外部リンクで開く。SNSの掲載とDM受付の確認は区別し、未確認の連絡先もその旨を表示する。
- 引き継いだ最終レビューの判定は ship。指摘は脚注の文字コントラスト1件で、共通スタイルの `.footnote` は `#526577` に修正済み。この記録はそのレビュー範囲と実装を整理したもので、追加のブラウザテストや全体監査は行っていない。

既存の `DESIGN.md` とデザイン用sidecarは維持する。本記録は京都府への通常の画面拡張に関する補足であり、全体のデザイン方針を置き換えない。
