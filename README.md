# 大阪の飲食店候補リスト

大阪府内の飲食店について、Webサイト制作の営業候補を地域別・S/A/B判定で閲覧する静的サイトです。2026年10月4日時点で **1,306店の暫定候補** を掲載しています。大阪市は276店です。

**重要:** 候補の全店について「独自Webサイトがない」「現在営業している」「独立経営である」と確認できたわけではありません。S/A/Bは店舗の品質評価ではなく、調査時点での条件との一致度です。大阪府内の全店舗を網羅したリストでもありません。連絡・利用前に必ず個別に再確認してください。

電話番号は公開された店舗紹介・事業用連絡先を店名と所在地で照合した **506店** に出典付きで掲載しています。残る800店は「未確認」です。公開名簿の調査対象一覧にも、元資料に事業用番号がある行だけ番号を表示します。掲載番号が現在も利用できるかは連絡前に再確認してください。

`dist/` がサイト本体です。各候補には調査元へのリンクを付けています。別画面の公開許可記録68,521件は条件未判定の調査対象で、1,306店の候補と合算できません。収集方法・除外条件・再現手順は [research/README.md](research/README.md) を参照してください。

元資料に含まれる営業者の個人名・個人住所などの生データは、このリポジトリに含めていません。

メール欄は全候補に追加し、既存の公開紹介ページ1,046件と補足検索から店舗用の連絡先を確認できた1店に、確認元リンクとmailtoリンクを掲載。残る1,305店は未確認。根拠は `research/email-evidence-2026-10-04.json`、表示用データは `dist/emails.js`。到達性は未検証です。
