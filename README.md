# 大阪の飲食店候補リスト

大阪府内の飲食店について、Webサイト制作の営業候補を地域別・S/A/B判定で閲覧する静的サイトです。2026年10月3日時点で **1,023店の暫定候補** を掲載しています。

**重要:** 候補の全店について「独自Webサイトがない」「現在営業している」「独立経営である」と確認できたわけではありません。S/A/Bは店舗の品質評価ではなく、調査時点での条件との一致度です。大阪府内の全店舗を網羅したリストでもありません。連絡・利用前に必ず個別に再確認してください。

`dist/` がサイト本体です。各候補には調査元へのリンクを付けています。別画面の公開許可記録68,521件は条件未判定の調査対象で、1,023店の候補と合算できません。収集方法・除外条件・再現手順は [research/README.md](research/README.md) を参照してください。

元資料に含まれる営業者の個人名・個人住所などの生データは、このリポジトリに含めていません。
